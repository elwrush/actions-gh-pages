# Visual Roadmap: Legendary Cities

**Model**: Shape E (Receptive Skills)
**Topic**: Legendary cities (Atlantis, El Dorado, Shangri-La).

| Stage | Activity | Layout ID | Visual / Content Note |
| :--- | :--- | :--- | :--- |
| **Lead-in** | Legendary Quiz (Fact/Fiction) | `schema_activation` | Use images of Atlantis and El Dorado. |
| **Pre-teach Vocab** | Matching (5 items) | `split_table` | Words: philosopher, earthquake, ritual, fictional, paradise. |
| **Gist / Scanning** | Ex 3 (Summary Scan) | `split_table` | 10 gap-fill items with 4-min timer. |
| **Main Task (Detail)**| Ex 5 (MCQ) & Ex 4 (Underline) | `split_table` | MCQ with icons for each city. |
| **Detailed Feedback**| Evidence Checking | `split_table` | Focus on finding specific data in the text. |
| **Post-task** | Ex 6 (Your Shangri-La) | `strategy` | Group discussion about dream cities. |

## Layout Suitability
- Use `schema_activation` for the lead-in to build curiosity.
- Use `split_table` for all main reading tasks to maintain a clean layout for students to follow.
- Ensure the **Mission** slide follows the Lead-in.
